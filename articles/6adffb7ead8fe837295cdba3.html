我对于AI、自媒体和生意的14条思考。

来源：林卿LinQ · 发布时间：Sun, 25 Oct 2026 03:00:00 +0000 · 查看微信原文

-

Halo，你好，见字如面，我是林卿 👋

国庆假期的时候，我去参加了生财有术南昌和赣州的线下聚会。

回来之后，陆陆续续整理了一些学习笔记，也顺便把自己过去一段时间关于AI、自媒体、SKILL和商业经营的一些思考重新梳理了一遍，整理在这儿，存档记录一下。

-

01.现阶段，如果想通过AI做视频自媒体，我觉得有一种内容生产方式比较值得尝试：

AI数字人＋真实视频素材、录屏、动效等混剪。

02.小账号不代表没有商业价值。

在某些垂直场景下，1000个精准用户的商业价值，确实可能高于1万个泛用户。

03.当越来越多人都能低成本生产内容，单纯的生产能力就可能越来越不值钱，反而是内容选题、专业理解、真实经验、个人判断，以及对目标用户需求的洞察……

这些软实力会变得更加重要。

04.想让AI写出来的内容越来越像自己，就得让AI真正了解自己，以及知道我究竟想表达什么。

05.比持续投喂AI更重要的，是让AI理解我为什么和怎么修改内容：

AI生成初稿 -> 人工修改 -> 正式发布 -> 真实数据反馈 -> 复盘初稿和终稿差异 -> 复盘内容表现 -> 提炼规律 -> 更新创作规则 -> 下一次继续使用……

06.在做SKILL之前，要先把实际的诉求、工作流程什么梳理清楚。

07.做SKILL，不要什么都默认从0开始：

明确需求 -> 检索成熟方案 -> 评估能否复用 -> 根据实际业务调整 -> 没有合适方案再自行封装。

08.想长期稳定使用SKILL，还需要把它放到真实的任务里调用测试，再根据实际结果，逐步修改，直到它能比较稳定地完成目标任务为止。

09.SKILL越来越多以后，需要增加更严格的触发规则。

10.做生意之前，先想清楚有哪些钱可以赚，自己准备赚什么钱，以及这些钱具体怎么赚。

11.对于中小品牌商家来说，在生意还没有跑通之前，复购、用户LIV价值就是个伪命题。

12.碰到有效的红利，就应该抓住红利、往死里干，集中资源把它做透。

13.规模本身不是优势，能够被低成本复制、并且持续产生利润的经营能力，才可能形成真正的优势。
